# PoE风格文字游戏 - 前期架构设计

## 1. 项目定位

单机文字游戏，核心玩法围绕 Path of Exile 1 的装备系统展开：
- 随机装备生成 + 词缀系统
- 通货驱动的装备改造
- 宝石镶嵌与辅助组合
- 巨型天赋树
- 终局地图探索

## 2. 设计原则

1. **装备即核心**：所有系统围绕"获取装备→改造装备→验证强度"循环
2. **深度优先**：宁可系统少但每个有深度，不做浅层堆砌
3. **文字可读**：信息密度高但清晰，用颜色/符号区分品质
4. **单机体验**：无需联机/赛季，但保留足够的build多样性

## 3. 模块划分

```
核心模块（MVP必须）:
├── M1: 角色系统（属性/防御/伤害）
├── M2: 装备系统（基底/词缀/品质/插槽）
├── M3: 通货系统（改造材料）
├── M4: 技能系统（主动宝石+辅助宝石+插槽组）
├── M5: 天赋树（节点网络+天赋点获取）
├── M6: 战斗系统（回合制/动作条）
└── M7: 掉落与刷图（区域探索+地图词缀）

扩展模块（后续版本）:
├── E1: 药剂系统
├── E2: 异常状态系统
├── E3: 升华职业
├── E4: 赛季机制（DLC式内容）
└── E5: 成就与图鉴
```

## 4. 技术选型

- **语言**: TypeScript
- **运行时**: Node.js（命令行交互）或浏览器（文字UI）
- **数据存储**: JSON文件存档
- **框架**: 无框架，纯逻辑层（与UI解耦）

## 5. 核心循环

```
探索区域 → 击杀怪物 → 获得通货/装备/宝石
                    ↓
        在背包中查看/改造装备
                    ↓
        配置技能插槽组
                    ↓
        点天赋树
                    ↓
        挑战更难区域（地图）→ 循环
```
