# 装备与通货系统详细设计

## 1. 基底系统（Base Items）

每种装备有多个基底类型，基底决定：
- 固有属性（Implicit）
- 插槽数量范围
- 属性需求（力量/敏捷/智力）
- 物品等级范围

## 2. 词缀池设计

### 词缀结构
词缀按 **Tier** 分级，每个 Tier 有独立的数值范围：

| Tier | 物品等级要求 | 数值范围 | 出现权重 |
|------|------------|---------|---------|
| T1   | 80+        | 最高    | 低      |
| T2   | 60+        | 较高    | 中低    |
| T3   | 40+        | 中      | 中      |
| T4   | 20+        | 较低    | 中高    |
| T5   | 1+         | 最低    | 高      |

### 词缀Roll规则

```
1. 确定词缀类别（前缀 or 后缀）
2. 从该类别的词缀池中，按权重随机选取一个词缀ID
3. 根据装备物品等级，过滤掉不符合的Tier
4. 在剩余Tier中，按权重随机选一个Tier
5. 在该Tier的min-max范围内随机一个值
6. 检查不重复（同一词缀ID不能出现两次）
```

## 3. 通货系统设计

### 通货清单（单机版，仅改造用途）

| 通货名 | 效果 | 稀有度 | 获取难度 |
|--------|------|--------|---------|
| 点金石 (Orb of Alteration) | 重掷魔法装备词缀 | 常见 | 低 |
| 附魔石 (Augmentation) | 为魔法装备添加1条词缀 | 常见 | 低 |
| 升华石 (Regal Orb) | 将魔法变稀有，添加1条词缀 | 稀有 | 中 |
| 混沌石 (Chaos Orb) | 重掷稀有装备全部词缀 | 稀有 | 中 |
| 崇高石 (Exalted Orb) | 为稀有装备添加1条高阶词缀 | 传说 | 高 |
| 淬火石 (Orb of Scouring) | 将装备清除为白色 | 常见 | 低 |
| 精炼石 (Divine Orb) | 重roll词缀数值不改词缀 | 稀有 | 中 |
| 磨刀石 (Blacksmith's Whetstone) | 武器品质+5% | 常见 | 低 |
| 护甲片 (Armourer's Scrap) | 护甲品质+5% | 常见 | 低 |
| 工匠石 (Jeweller's Orb) | 随机改变插槽数量 | 稀有 | 中 |
| 链接石 (Orb of Fusing) | 随机改变插槽连接 | 稀有 | 中 |
| 变色石 (Chromatic Orb) | 随机改变插槽颜色 | 常见 | 低 |
| 机会石 (Orb of Chance) | 白色装备随机变为蓝/黄/橙 | 稀有 | 中 |

### 改造流程

```
白色装备 + 机会石 → 蓝色(1-2前缀或后缀) / 黄色(3-6词缀) / 橙色(固定)
白色装备 + 淬火石 → 保持白色（清除用）
白色装备 + ?      → 需要其他通货组合？

魔法装备 + 点金石 → 重roll全部词缀
魔法装备 + 附魔石 → 追加1条词缀（必须有空位）
魔法装备 + 升华石 → 变稀有，追加1条词缀

稀有装备 + 混沌石 → 重roll全部词缀
稀有装备 + 崇高石 → 追加1条高阶词缀（6词缀时无效）
稀有装备 + 精炼石 → 只重roll数值

任意装备 + 淬火石 → 清除所有词缀（变白）
```

## 4. 装备生成算法

```typescript
function generateItem(baseId: string, itemLevel: number, rarity: Rarity): Item {
  const base = getBase(baseId);
  
  // 1. 确定插槽数和颜色
  const socketCount = randomRange(base.sockets.min, base.sockets.max);
  const sockets = generateSockets(socketCount, base);
  
  // 2. 固有属性
  const implicit = base.implicit.map(stat => ({
    ...stat,
    rolled: randomRange(stat.min, stat.max)
  }));
  
  // 3. 根据稀有度roll词缀
  let prefixes: Affix[] = [];
  let suffixes: Affix[] = [];
  
  if (rarity === Rarity.Magic) {
    // 蓝色：随机 0-1 前缀 + 0-1 后缀
    if (Math.random() < 0.6) prefixes.push(rollAffix("prefix", base, itemLevel));
    if (Math.random() < 0.6) suffixes.push(rollAffix("suffix", base, itemLevel));
    // 确保至少有1条
    if (prefixes.length === 0 && suffixes.length === 0) {
      Math.random() < 0.5
        ? prefixes.push(rollAffix("prefix", base, itemLevel))
        : suffixes.push(rollAffix("suffix", base, itemLevel));
    }
  } else if (rarity === Rarity.Rare) {
    // 黄色：3前缀+3后缀上限
    const prefixCount = randomRange(1, 3);
    const suffixCount = randomRange(1, 3);
    for (let i = 0; i < prefixCount; i++) {
      const affix = rollAffix("prefix", base, itemLevel, prefixes);
      if (affix) prefixes.push(affix);
    }
    for (let i = 0; i < suffixCount; i++) {
      const affix = rollAffix("suffix", base, itemLevel, suffixes);
      if (affix) suffixes.push(affix);
    }
  }
  
  return {
    id: generateId(),
    name: generateName(rarity, base),
    type: base.type,
    slot: base.slot,
    rarity,
    itemLevel,
    base,
    implicit,
    prefixes,
    suffixes,
    sockets,
    quality: 0
  };
}
```

## 5. 掉落系统

```
怪物掉落判定流程：
1. 击杀怪物 → 通货掉落判定 → 词缀掉落判定 → 装备掉落判定
2. 装备掉落：先确定装备部位 → 从该部位基底池随机 → 确定物品等级(≤怪物等级) → 确定稀有度
3. 稀有度权重：
   - Normal: 60%
   - Magic:  25%
   - Rare:   12%
   - Unique: 3%（受IIR加成影响）
4. 通货掉落：常见通货80%，稀有通货18%，传说通货2%
5. 地图词缀影响：
   - "物品稀有度 +50%" → 稀有度权重偏移
   - "物品数量 +30%" → 掉落物品数量增加
   - "怪物额外生命" → 击杀难度增加但奖励更好
```
