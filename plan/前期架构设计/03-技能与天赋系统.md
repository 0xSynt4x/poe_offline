# 技能与天赋系统设计

## 1. 技能宝石系统

### 核心概念
- **主动宝石**：放在装备插槽中，提供一个可使用的技能
- **辅助宝石**：放在同一插槽组（Link）中，修改/增强主动技能
- **插槽组**：装备上相互连接的插槽构成一组，组内宝石互相作用
- **颜色匹配**：红色宝石需要力量系辅助，绿色需敏捷系，蓝色需智力系

### 插槽组示例

```
装备: 6连胸甲
插槽: [红][红][蓝][蓝][绿][绿]
连接: 1-2-3-4-5-6 (全部相连 = 6-Link)

槽1(红): 熔岩打击 (主动) ← 赋予技能
槽2(红): 多重打击 (辅助) ← 攻击3次
槽3(蓝): 元素伤害增加 (辅助) ← +30%元素伤害
槽4(蓝): 暴击几率 (辅助) ← +暴击
槽5(绿): 集中效应 (辅助) ← +伤害 +范围减小
槽6(绿): 元素穿透 (辅助) ← 忽略抗性

→ 计算最终技能：熔岩打击 × 3次 × 元素增伤 × 暴击加成 × 集中效应 × 穿透
```

### 辅助宝石交互规则

```
1. 标签匹配：辅助宝石只能辅助具有对应标签的主动技能
   - "火焰"辅助 → 只对火系技能有效
   - "攻击"辅助 → 只对攻击类技能有效
   
2. 互斥规则：
   - "施法速度" + "攻击速度" 不能同时辅助一个技能（标签冲突）
   - "集中效应" + "增大范围" 互斥
   
3. 特殊交互：
   - Cast on Critical Strike → 攻击暴击时自动施放法术
   - Cast when Damage Taken → 受伤时自动施放
   - Totem/Trap/Mine → 改变技能施放方式
```

### 技能伤害计算公式

```
最终伤害 = 基础伤害 × (1 + 宝石等级加成)
         × (1 + 装备伤害加成 + 天赋伤害加成)    [加算]
         × (1 + 辅助宝石乘率1)
         × (1 + 辅助宝石乘率2)
         × (1 + 暴击乘率)                       [如果暴击]
         × (1 - 敌方抗性/100)                    [抗性减伤]
```

## 2. 天赋树设计

### 概念
- 大型节点网络（PoE1风格，但可以缩小到适合文字游戏的规模）
- 分为多个区域，每个区域偏向不同属性
- 节点类型：小节点(基础属性) → 中节点(中等加成) → 大点(Notable) → 关键天赋(Keystone)
- 玩家通过升级/完成任务获得天赋点

### 天赋树区域划分

```
    [力量区域]          [混合区域]          [智力区域]
   物理伤害/生命       攻速/暴击/防御       法术/能量护盾/魔力
   重甲/格挡          闪避/混合抗性        光环/诅咒

    [敏捷区域]          [中心区域]          [混沌区域]
   攻速/闪避/命中      通用加成/资源效率     混沌伤害/中毒/流血
   暴击/投射物         药剂效果             持续伤害
```

### 天赋点获取

```
升级奖励：
- 每2级获得1个天赋点
- 角色等级上限：100
- 天赋点总计：约50个基础点 + 任务奖励点(约15个) = 65点

升华天赋：
- 完成特定挑战获得(每职业3个升华点)
- 提供改变玩法的核心能力
- 示例："暴击流派"升华 → 暴击伤害+50%，但非暴击伤害-30%
```

## 3. 升华职业

```
力量系:
├── 战神 (Berserker): 狂暴叠加, 伤害递增, 受伤递增
├── 守卫 (Guardian): 光环效果+50%, 持续伤害降低
└── 冠军 (Champion): 穿刺机制, 持续时间增加

敏捷系:
├── 刺客 (Assassin): 暴击率/暴击伤害, 毒伤害加成
├── 游侠 (Deadeye): 投射物伤害, 远程范围
└── 面纱行者 (Pathfinder): 药剂效果, 元素伤害

智力系:
├── 奥术师 (Inquisitor): 元素穿透, 非伤害型异常
├── 秘术师 (Occultist): 混沌伤害, 能量护盾
└── 元素使 (Elementalist): 元素伤害, 元素异常效果
```
