# 战斗与终局系统设计

## 1. 战斗系统

### 战斗模式：回合制动作条

```
┌─────────────────────────────────────────┐
│  行动条 (Action Bar)                      │
│  [玩家]───[怪物1]───[怪物2]───[玩家]──... │
│  速度越快，行动越频繁                        │
└─────────────────────────────────────────┘

每个行动回合：
1. 选择行动（攻击/技能/药剂/逃跑）
2. 计算命中/闪避
3. 计算伤害（含暴击）
4. 应用异常状态
5. 应用持续伤害（点燃/流血/中毒）
6. 检查死亡
7. 推进行动条
```

### 行动条速度计算

```
行动速度 = 基础速度 × (1 + 攻击速度加成%)     [攻击类]
行动速度 = 基础速度 × (1 + 施法速度加成%)     [法术类]

基础行动间隔 = 1000ms (1秒)
当前间隔 = 基础间隔 / 行动速度

示例：
- 基础速度 1.0, 攻击速度+50% → 速度=1.5, 间隔=667ms
- 多重打击：额外2次攻击，每次间隔×1.3（速度惩罚）
```

### 伤害计算详解

```
物理伤害：
  rawDamage = weaponDps × (1 + 全局物理伤害加成)
  finalDamage = rawDamage × (1 - 敌方物理减伤%)

元素伤害：
  rawDamage = skillBase × (1 + 元素伤害加成 + 对应元素伤害加成)
  effectiveDamage = rawDamage × (1 - max(敌方抗性 - 玩家穿透, 0) / 100)

暴击判定：
  isCrit = random() < (基础暴击率 × (1 + 暴击率加成%))
  如果暴击: damage *= (2 + 暴击伤害加成)

最终伤害 = effectiveDamage × (暴击倍率)
```

```typescript
interface Monster {
  id: string;

  level: number;

// Rare: 3-4个词缀
// Unique: 固定词缀，特殊机制（Boss）
```

## 2. 区域探索系统

### 探索结构

```
游戏世界 = 章节(Act) → 区域(Area) → 房间(Room)

章节1: 荒芜之地
├── 1-1 枯萎森林     [Lv1-5]
├── 1-2 泥沼村落     [Lv4-8]
├── 1-3 下水道       [Lv7-11]
├── 1-4 铁匠铺       [Lv10-13]
└── 1-Boss 腐化领主  [Lv13]

章节2: 王都废墟
├── 2-1 破碎城墙     [Lv13-16]
├── ...
```

### 房间类型

```
普通房间:   遭遇普通怪物
精英房间:   遭遇精英/Magic怪物, 掉落更好
宝箱房间:   打开宝箱获得通货/装备
商店房间:   NPC商人, 通货兑换
传送房间:   传送到下一个区域
Boss房间:   章节Boss, 固定掉落
```

## 3. 终局地图系统（Endgame）

### 地图概念

通关所有章节后，解锁地图系统：
- 每张地图是一个区域，有固定难度等级
- 地图本身可以改造（像装备一样加词缀）
- 更难的地图 = 更好的掉落

### 地图数据

```typescript
interface Map {
  id: string;
  name: string;
  tier: number;           // 地图等级 1-16
  baseLevel: number;      // 基础怪物等级 (68 + tier)
  
  // 地图词缀（类似装备词缀）
  mods: MapMod[];
  
  // 已完成
  completed: boolean;
  bonus: boolean;         // 红图奖励
}

interface MapMod {
  id: string;
  name: string;
  description: string;
  effects: MapModEffect[];
}

// 地图词缀示例
// "纷争的" - 怪物+80%伤害
// "不洁的" - 怪物+45%混沌抗性
// "丰饶的" - 掉落数量+30%
// "稀有的" - 稀有度+50%
// "坚韧的" - 怪物+50%生命
```

### 地图改造

```
地图可使用通货改造：
- 淬火石: 清除所有词缀
- 混沌石: 重roll词缀
- 崇高石: 添加1条新词缀
- 工匠石: 改变地图品质(影响奖励)

策略：玩家需要平衡地图难度(词缀加成)与可玩性
```

### 终局循环

```
刷图 → 获取更好的地图 → 获取更好的装备/通货 → 挑战更高难度地图 → 循环

地图掉落规则：
- T1-T5地图: 在章节区域掉落
- T6-T10地图: 由T1-T5地图掉落
- T11-T15地图: 由T6-T10地图掉落
- T16地图: 由T11-T15地图 + Boss掉落
```

## 5. 开发阶段规划

```
Phase 1 - 最小可玩版本 (MVP):
  ├── 基础装备系统（白色/蓝色/黄色装备 + 词缀）
  ├── 简单通货（5种核心通货）
  ├── 3-4个主动技能 + 5-6个辅助技能

  ├── 回合制战斗
  └── 章节1内容（约20个房间）

  ├── 完整天赋树
  ├── 宝石等级升级系统
  ├── 升华职业

  ├── 章节2-3内容
  └── 药剂系统

Phase 3 - 终局内容:
  ├── 地图系统
  ├── 地图改造
  ├── 高级词缀池
  ├── Boss机制
  └── 无限刷图循环
```
