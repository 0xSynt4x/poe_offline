# 构建方案：单HTML文件输出

## 1. 构建目标

最终产物：一个独立的 `.html` 文件，包含所有JS/CSS/数据，双击即可在浏览器中运行。

## 2. 技术栈

```
开发时:
├── TypeScript (类型安全 + 逻辑)
├── CSS (样式)
├── JSON (游戏数据：词缀/装备/宝石)
└── esbuild (打包)

构建流程:
  TS/CSS/JSON → esbuild → 单个HTML文件
```

## 3. 项目结构

```
project/
├── src/
│   ├── index.html          # 模板HTML（含CSS）
│   ├── main.ts             # 入口
│   ├── models/             # 数据模型
│   ├── systems/            # 逻辑系统
│   ├── data/               # 游戏数据(JSON)
│   └── ui/                 # UI渲染逻辑
├── build.ts                # 构建脚本
├── package.json
└── tsconfig.json
```

## 5. HTML模板结构

```
单HTML文件结构:
├── <style>        所有CSS内联
├── <div id="app"> 主容器
│   ├── 顶部: 角色状态栏
│   ├── 左侧: 游戏主区域（探索/战斗/改造）
│   ├── 右侧: 背包/装备栏
│   └── 底部: 日志/操作反馈
└── <script>       所有JS内联
```
