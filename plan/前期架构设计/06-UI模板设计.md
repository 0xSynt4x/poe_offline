# UI模板设计

## 布局结构

```
┌──────────────────────────────────────────────────────────┐
│  [角色名 Lv.XX]  ❤️ 850/1000  🔵 120/150  🛡️ 1500      │  ← 顶栏
├──────────────────────────────────┬───────────────────────┤
│                                  │  ┌─装备栏──────────┐  │
│                                  │  │ [头]    [项链]   │  │
│          游戏主区域               │  │ [胸]    [戒指1]  │  │
│     (探索/战斗/改造/对话)          │  │ [手]    [戒指2]  │  │
│                                  │  │ [腰]             │  │
│                                  │  │ [脚]    [副手]   │  │
│                                  │  │ [武器]           │  │
│                                  │  └────────────────┘  │
│                                  │  ┌─背包────────────┐  │
│                                  │  │ 通货 × 数量       │  │
│                                  │  │ 装备列表          │  │
│                                  │  │ 宝石列表          │  │
│                                  │  └────────────────┘  │
├──────────────────────────────────┴───────────────────────┤
│  [操作栏]  1:技能  2:技能  Q:查看  W:天赋  E:药剂        │  ← 底栏
├──────────────────────────────────────────────────────────┤
│  > 骸骨战士受到了 45 点火焰伤害                           │  ← 日志
│  > 你的裂风斩造成了 128 点物理伤害                        │
│  > 骸骨战士 被消灭了                                     │
└──────────────────────────────────────────────────────────┘
```

## CSS配色方案 (PoE暗色风格)

- 背景: #1a1a2e (深蓝黑)
- 面板: #16213e (暗蓝)
- 边框: #0f3460 (蓝边框)
- 文字: #e0e0e0 (浅灰白)
- 生命条: #e74c3c (红)
- 魔力条: #3498db (蓝)
- 护盾条: #f39c12 (金)
- 伤害数字: #ff6b6b (红)
- 治疗数字: #2ecc71 (绿)
- 稀有度颜色: 白#ccc / 蓝#6cf / 黄#ff0 / 橙#f90

## 抗性颜色
- 火抗: #e74c3c
- 冰抗: #3498db
- 雷抗: #f1c40f
- 混沌抗: #9b59b6
