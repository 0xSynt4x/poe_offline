## 二、逐系统详细差距

### 1. 装备系统 🟡

**已实现 ✅**
- 30+基底（武器/盾牌/防具/首饰），按槽位分
- 前缀20+、后缀15+词缀池，5级Tier，权重随机
- Normal/Magic/Rare品质生成
- 装备品质字段（quality）
- 基底隐性属性（Implicit）

**差距 ❌**
| 缺失项 | PoE1描述 | 优先级 |
|--------|---------|--------|
| Unique装备 | 300+独有装备，特殊词缀+独特机制 | P1 |
| 装备需求检查 | 力量/敏捷/智力/等级需求不检查 | P1 |
| 品质影响数值 | PoE1武器品质影响基础伤害，防具品质影响防御 | P2 |
| 物品等级下限 | 某些词缀需要物品等级≥某值 | P2 |
| 连接规则细化 | PoE1中武器类型影响可出颜色概率 | P2 |
| 药剂基底 | 生命药剂/魔力药剂/复合药剂/功能药剂 | P1 |
| 甲片/磨刀石实际效果 | 目前+5%/次，PoE1是+1%/次 | P1 |
| 装备锁定（腐化后） | 腐化物品无法再使用通货 | P3 |

### 2. 通货系统 🟡

**已实现 ✅**

|---------|---------|--------|

| 瓦尔球（Vaal Orb） | 腐化物品：随机改变/锁定 | P1 |
| 祝福石（Blessed Orb） | 重roll隐性属性数值 | P2 |
| 玻璃弹珠（Glassblower's Bauble） | 药剂品质+5% | P2 |

| 富集石（Augment）正确行为 | 魔法装备添加一条随机词缀 | P0 |

1. `applyCurrency()` 硬编码标签 `"armor"` → 武器/首饰用通货时roll出防具词缀

## 三、Bug与数值问题

### P0（必须修复）
1. `applyCurrency()` 硬编码 `"armor"` 标签 → 武器roll出防具词缀
2. `upgrade_rarity` effect语义混乱（机会石和升华石共用同一type）
3. 宝石掉落显示"未实现"
4. 任务系统完全未接入（数据有了但没用）
5. 装备品质（quality）未影响数值计算

### P1（重要修正）
1. 磨刀石/护甲片应+1%/次而非+5%/次
2. 升级经验公式过于简单（每100exp升1级）
3. 玩家基础属性固定（30/20/15）应根据职业变化
4. 玩家起始无装备和技能
5. 战斗掉落过于随机（应与怪物等级/区域相关）
6. 怪物没有技能/特殊能力（Boss的abilities数据没用上）
7. 天赋树属性加成覆盖了装备加成（应累加）

### P2（体验优化）
1. 背包上限50太小 → 应有仓库页概念
2. 战斗日志不够丰富（缺伤害数值细节）
3. 区域探索重复点击太单调（缺节奏感）
4. 地图系统没有真正的探索流程

## 五、与PoE1的体验差距总结

| 体验维度 | PoE1 | 当前游戏 | 差距 |
