# 项目进度 - 2026-08-26

## 项目概述

PoE风格文字游戏，基于Path of Exile 1的核心系统设计，单HTML文件输出。

## 技术栈

- TypeScript + CSS + JSON
- esbuild 打包为单HTML文件
- 输出：`dist.html` (90.7 KB)

## 已完成系统

### 1. 项目架构 ✅
```
src/
├── index.html          # HTML模板
├── style.css           # CSS样式（暗色PoE风格）
├── main.ts             # 主入口
├── models/types.ts     # 核心数据类型
├── data/               # 游戏数据
│   ├── affixes.ts      # 词缀池（20+前缀，15+后缀）
│   ├── bases.ts        # 基底装备（30+种）
│   ├── currencies.ts   # 通货系统（14种）
│   ├── gems.ts         # 宝石数据（16主动+15辅助）
│   └── passiveTree.ts  # 天赋树（22节点）
├── systems/            # 游戏系统
│   ├── affix.ts        # 词缀系统+装备生成+通货改造
│   ├── gemLink.ts      # 宝石链接+技能计算
│   ├── combat.ts       # 战斗系统（回合制+行动条）
│   └── passiveTree.ts  # 天赋树逻辑

    ├── controller.ts   # 主UI控制器
    └── passiveTreeUI.ts # 天赋树UI
```

### 2. 装备系统 ✅
- **基底系统**：30+种基底，按槽位分类（武器/盾牌/头盔/胸甲/手套/靴子/腰带/项链/戒指）
- **词缀系统**：完整词缀池，5级Tier，按权重随机
  - 前缀：生命/魔力/护甲/闪避/ES/物理伤害/元素伤害/混沌伤害/法术伤害等
  - 后缀：抗性/属性/攻速/暴击/命中/偷取等
- **装备生成**：支持Normal/Magic/Rare品质，自动roll词缀
- **装备显示**：HTML格式输出，按稀有度着色

### 3. 通货系统 ✅
- **14种通货**，3个稀有度等级：
  - 常见：点金石/附魔石/淬火石/磨刀石/护甲片/变色石
  - 稀有：升华石/混沌石/精炼石/工匠石/链接石/机会石
  - 传说：崇高石/抹除石
- **改造逻辑**：淬火石清除词缀、混沌石重roll、精炼石改数值等

### 4. 技能系统 ✅
- **16种主动宝石**：近战/火焰/冰冷/闪电/混沌技能
- **15种辅助宝石**：伤害乘率/攻速/暴击/范围/穿透/连锁/分裂等
- **宝石组合**：标签匹配+互斥规则+伤害计算
- **技能计算**：基础伤害×(1+加成)×辅助乘率×暴击

### 5. 战斗系统 ✅
- **回合制战斗**：行动条决定出手顺序
- **伤害计算**：命中/闪避/暴击/护甲/抗性减伤
- **怪物系统**：随机生成怪物，支持多怪物战斗
- **战斗掉落**：通货/装备掉落

### 6. 天赋树系统 ✅
- **22个节点**，4个区域：
  - 力量之路：生命/护甲/物理伤害
  - 敏捷之道：闪避/攻速/暴击
  - 智慧之道：法力/法术伤害/能量护盾
  - 中心枢纽：连接三大路径
- **节点类型**：普通/重要(notable)/关键(keystone)
- **分配逻辑**：前置条件检查、链式取消分配
- **属性加成**：自动计算并应用到玩家属性

### 7. UI系统 ✅
- **顶栏**：角色名/等级/生命/魔力/护盾/抗性
- **主区域**：场景描述+交互按钮（探索/战斗/休息）
- **侧边栏**：装备栏/技能栏/背包（装备/通货/宝石标签）
- **底部**：操作按钮（1-3技能/Q查看/W天赋/E药剂）
- **日志**：战斗日志显示
- **天赋树模态框**：可视化节点+分配+详情面板

## 游戏循环

1. 场景探索 → 随机事件（战斗/奖励/空）
2. 战斗 → 使用技能击败怪物 → 获得掉落
3. 装备管理 → 查看/装备/卸下装备
4. 通货改造 → 使用通货修改装备词缀
5. 天赋分配 → 提升角色属性
6. 循环
