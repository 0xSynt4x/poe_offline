# 修改记录 - 修复通货Bug并接入任务系统

- **时间**: 2026-08-26
- **修改类型**: Bug修复 + 新功能

## 修改内容

### 1. 修复通货系统Bug

**P0修复 - orb_of_chance 与 regal_orb 共用 effect type 问题：**
- `types.ts`：新增 `CurrencyEffect` 类型 `{ type: "chance" }`
- `currencies.ts`：`orb_of_chance` 的 effect 从 `"upgrade_rarity"` 改为 `"chance"`
- `affix.ts`：新增 `chance` case — 白色装备70%变魔法（1-2词缀），30%变稀有（4-6词缀），符合PoE1机会石行为

**修复 identify 行为错误：**
- `affix.ts`：`identify` case 改为空操作（当前无unidentified概念，原实现错误地给装备添加随机词缀）

**修复 link/color 未使用 socket 系统：**
- `affix.ts`：`link` case 改为调用 `createSockets()` 重新生成（保持孔数由装备类型决定）
- `affix.ts`：`color` case 改为调用 `rerollSocketColors()` 保持孔数和链接不变，只随机颜色
- `affix.ts`：新增 `rerollSocketColors` 导入

**确认标签Bug已修复：**
- `applyCurrency()` 中已使用 `baseData?.tags ?? []` 从 `ALL_BASES` 获取实际标签，非硬编码 `"armor"`

### 2. 接入任务系统

**ZoneSystem 扩展（zone.ts）：**
- `GameState` 新增 `completedQuests`、`pendingRewards`、`activeQuests` 字段
- 构造器支持从存档恢复任务状态
- 新增方法：
  - `refreshAvailableQuests()` — 根据等级和前置任务刷新可接取任务
  - `checkQuestCompletion()` — zone完成时检查任务是否满足条件
  - `getPendingRewardQuests()` — 获取待领取奖励的任务
  - `claimQuestReward(questId)` — 领取任务奖励（经验+通货+装备）
  - `getAllQuests()` — 获取所有任务列表（含完成状态）
  - `updateChapter()` — 根据完成区域推进章节
- `completeZone()` 中自动触发任务检查

**UI 集成（controller.ts）：**
- `updateQuestUI()` — 渲染任务面板（待领取奖励高亮+章节任务列表）
- `claimQuestReward()` — 领取奖励交互
- `leaveZone()` / `endCombat()` 中检查并通知任务完成
- `updateAllUI()` 中包含任务面板更新

**存档系统（saveLoad.ts）：**
- `SaveData.zoneProgress` 新增 `completedQuests`、`pendingRewards`、`activeQuests` 字段
- 保存/加载时持久化任务进度

**样式（style.css）：**
- 新增任务面板样式（`.quest-panel`、`.quest-reward-item`、`.quest-claim-btn` 等）
- 奖励领取按钮带脉冲动画
