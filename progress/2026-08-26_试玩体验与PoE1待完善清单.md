# 修改记录 - 试玩体验与PoE1待完善清单

- **时间**: 2026-08-26
- **修改类型**: 文档

## 修改内容

本次基于构建后的 `dist.html` 实际试玩，并结合源码核对，记录当前版本与 PoE1 的实际体验差距。

## 实际试玩路径

1. 打开游戏，进入主菜单。
2. 点击「新游戏」，进入区域选择。
3. 进入「枯萎森林」。
4. 点击「探索」，实际遇到宝箱并获得通货与经验。
5. 再次探索，进入战斗。
6. 点击右侧技能名称「撕裂」，完成玩家攻击；等待约 0.5 秒后敌人自动攻击。
7. 打开「天赋树」，看到 22 个节点和 5 点天赋点。
8. 打开通货标签，确认可查看掉落通货；打开宝石标签，显示「宝石系统（未实现）」。

## 试玩结论

当前版本已经具备一个可运行的 PoE 风格文字游戏骨架：新游戏、区域选择、探索随机事件、战斗、技能、药剂、掉落、任务面板、天赋树和存档入口都能打开。其中区域探索和战斗是已经连通的，不是纯静态 UI。

但核心循环还没有达到 PoE1 的「探索 → 战斗 → 装备/宝石升级 → 构筑变化 → 推进区域」闭环。最大问题不是单个系统完全不存在，而是已有系统之间的连接和反馈不够完整，玩家会频繁遇到「看到了入口，但不知道下一步怎么用」的情况。

## 与 PoE1 的主要差距

### P0：先修复“能不能顺畅玩”

- **战斗操作提示不明显**：战斗界面只显示敌人和血条，技能栏仍在右侧，缺少当前回合、可用技能按钮、技能费用和行动反馈。实际试玩中需要猜测点击「撕裂 (15)」才能攻击。
- **战斗日志信息不够本地化**：日志显示 `physical`，应显示「物理」；伤害、命中、暴击、抗性减免等信息也应统一为玩家可读文本。
- **技能/宝石没有掉落闭环**：战斗掉落触发时仍记录「获得宝石（未实现）」，宝石背包直接显示「宝石系统（未实现）」。PoE1 中技能宝石是升级构筑的核心掉落和任务奖励。
- **任务奖励需要实际打通**：任务面板能显示任务，但试玩前段没有明显的任务目标进度、完成条件反馈和奖励选择流程。应至少保证击杀/区域完成后能明确显示完成，并领取经验、通货或技能宝石。
- **开始状态与 PoE1 差异大**：新角色直接为 Lv.10，有 3 个技能和 5 点天赋，但没有初始装备；同时顶部角色属性与实际角色状态的代入感较弱。需要明确是“测试角色”还是正式开局。

### P1：补齐最影响构筑的系统

- **装备掉落概率和装备使用反馈不足**：试玩一次探索通常只能看到通货/经验，装备掉落概率低；需要更稳定的早期装备引导、装备比较和装备需求检查。
- **装备与角色属性计算不完整**：装备、天赋、基础属性、品质对生命、防御、伤害、抗性的累加关系需要统一，避免某一类计算覆盖另一类加成。
- **孔、链接、宝石镶嵌流程不完整**：已有孔和链接数据、装备详情 UI，但需要稳定实现装备选择、镶嵌、取下、辅助宝石连接判定和技能组结果展示。
- **通货使用仍需严格对齐 PoE1**：重点检查武器/首饰重铸时的词缀标签、机会石与升华石行为、炼金石、增幅石、品质通货、孔和链接通货，以及 3 前缀 + 3 后缀上限。
- **药剂系统需要进入战斗策略**：当前已有 5 槽、充能、生命/魔力/功能药剂，但试玩中药剂主要是静态槽位。应显示充能变化、持续效果、功能药剂增益和使用后的敌方回合反馈。
- **敌人缺少技能和特殊能力**：当前骸骨战士主要进行普通攻击，Boss 数据和状态异常需要真正影响战斗。至少先接入点燃、流血、中毒、冻结、感电和眩晕中的基础版本。
- **天赋树需要职业/起点差异**：当前 22 节点可以演示分配逻辑，但与 PoE1 的大型职业化天赋树差距很大。第一阶段不必直接做 1300 节点，先提供 3 个职业起点和 2~3 条可形成不同玩法的路线。

### P2：补内容和长期目标

- **剧情内容严重不足**：当前可见内容为第 1 章 5 个区域和第 2 章 1 个区域，PoE1 是 10 章完整流程。需要先完成 3~4 章可玩的短流程，再扩展到完整章节。
- **NPC、商店和技能宝石任务奖励未形成玩法**：数据已有部分定义，但需要对话、购买、任务交付和奖励选择界面。
- **终局地图还偏框架**：已有地图仪和地图数据，但需要真正实现开启地图、刷怪、地图词缀影响、地图掉落、完成结算和高级地图循环。
- **独特装备完全缺失**：PoE1 的 Unique 不只是更高数值，而是改变技能或构筑规则。可以先做 10 件有明确机制的示例装备。
- **升华系统完全缺失**：应在章节推进后提供试炼和升华选择，否则角色成长的中期目标不足。
- **经济与交易缺失**：当前没有 NPC 兑换、商店定价、玩家交易或市场。单机原型可先做 NPC 通货兑换和商店，再考虑玩家市场。

## 建议实现顺序

### Phase 0：打通 15~30 分钟核心闭环

- [ ] 重做战斗操作区：明确当前行动者，技能显示为可点击按钮，并显示费用/伤害/冷却或行动状态。
- [ ] 修正战斗日志中文化和伤害明细。
- [ ] 实现技能宝石掉落、背包展示、装备孔镶嵌和取下。
- [ ] 接入 1 条主线任务：击杀目标 → 完成提示 → 领取经验/通货/宝石奖励。
- [ ] 给正式新角色配置合理的 Lv.1 起始装备、技能和药剂；保留 Lv.10 测试角色作为开发入口。
- [ ] 增加稳定的早期装备掉落，并支持点击查看、装备、比较。

### Phase 1：形成构筑决策

- [ ] 接入宝石等级和经验。
- [ ] 完善辅助宝石链接、技能组计算和资源消耗。
- [ ] 实现基础异常状态和敌人技能。
- [ ] 修复通货词缀标签、稀有度行为、品质数值和词缀上限。
- [ ] 增加 3 个职业起点和一小组有分支意义的天赋路线。
- [ ] 增加 10 件 Unique 示例装备。
- [ ] 增加 NPC 商店和技能宝石任务奖励。

### Phase 2：内容与终局

- [ ] 完成第 3~4 章可玩内容，再逐步扩展到 10 章。
- [ ] 完善地图仪的地图探索、词缀效果和掉落循环。
- [ ] 增加升华试炼与升华天赋。
- [ ] 增加工艺台、精髓、化石、瓦尔球和腐化锁定。
- [ ] 增加 NPC 兑换与基础交易/市场能力。

## 一句话评价

当前项目已经从静态界面进入“可操作原型”阶段，但更接近 PoE1 的系统演示版，而不是完整 ARPG 循环。下一步最值得做的不是继续堆更多数据，而是优先打通“战斗操作 → 宝石/装备掉落 → 装备镶嵌 → 构筑变化 → 任务推进”这条玩家能明确感知的主循环。
